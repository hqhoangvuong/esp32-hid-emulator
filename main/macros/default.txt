# Simulates a developer working in VS Code. Syntax:
#   TYPE <text>         type text with human-like timing (occasional typos get corrected)
#   KEY <combo>         e.g. ENTER, TAB, CTRL+S, ALT+TAB, F5, CTRL+GRAVE (the ` key)
#   MOVE <dx> <dy>      move the mouse by a relative offset along a curved path
#   CLICK [LEFT|RIGHT|MIDDLE]
#   SCROLL <n>          positive = up, negative = down
#   WAIT <ms>           fixed delay
#   IDLE <min> <max>    random delay in ms
#   LOOP                jump back to the first line (repeat forever)
#
# Before starting: focus the VS Code window with the editor active. All typing goes into
# an untitled scratch tab (plain text, so no auto-indent or auto-closing brackets), which is
# cleared at the end of every loop. Code lines have no leading spaces for the same reason.
# Mouse moves are paired so the cursor ends where it started.
